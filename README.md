# AI Murder Mystery

Author: Tad Decker
version 0.0.1

Interactive murder mystery game powered by Ollama AI.

## Setup

1. Install dependencies: `npm install`
2. Start Ollama: `ollama serve`
3. Run game: `node Main.js`

## Gameplay

- Choose suspects to interrogate
- Ask questions to solve the murder
- Type 'quit' to exit conversations
